# CARMA Vehicle Novatel Configuration Files

These files contain the configuration commands used to set up the Novatel PwkPak7D (PwrPak7D-E2 for the White Pacifica) GNSS receivers. These commands are run once, and store their data in non-volatile memory so they persist between reboots

## Steps to run these commands on a Novatel receiver

1. Install the Novatel Application Suite from [Novatel Software Downloads](https://novatel.com/support/support-materials/software-downloads)
2. Run the Novatel Application Suite
3. If this is first time connecting, connect to the receiver in the application suite over USB; otherwise connect over ethernet at port 3002 or port 2000
4. Select the terminal tab at the top under tools menu
5. ONE LINE AT A TIME, paste in the commands of the respective config file
